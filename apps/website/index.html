YOUR ACCOUNT. YOUR INFRASTRUCTURE.
{}

Meet your new cache.

Cloudflare creates a repository, provisions a private R2 bucket, and asks you to set a cache token.

Deploy to Cloudflare ↗

Requires a Cloudflare account with R2 enabled.

.moon/workspace.yml
remote:
  api: "http"
  host: "https://YOUR-WORKER.workers.dev"
  auth:
    token: "MOON_REMOTE_CACHE_TOKEN"
  cache:
    instanceName: "your-org/your-repo"
    verifyIntegrity: true

Replace the host with your deployed Worker URL. Choose a stable instance name for each repository.

Namespaces separate object keys. The shared token can access all instances.

YOUR SHELL / CI ENVIRONMENT
# Use your Worker's CACHE_TOKEN value.
export MOON_REMOTE_CACHE_TOKEN="YOUR_CACHE_TOKEN"

# Run a cacheable task.
moon run app:build

Store the same value as a secret in your CI provider. Keep real tokens out of committed configuration files.

In workspace.yml, auth.token names the environment variable. If it’s absent, moon disables remote caching.

A FEW GOOD QUESTIONS

Before your
next build.

Is Remoshu a hosted service?+

Remoshu is a self-hosted GitHub template. You deploy it into your own Cloudflare account and operate your own cache. This website introduces the project; it isn’t a shared cache endpoint.

What does it cost to run?+

Remoshu is MIT licensed. You pay Cloudflare for your usage. R2 has free internet egress; storage, Worker requests, and R2 operations can still incur charges. Review R2 pricing and Workers pricing for your workload.

Who can access the cached artifacts?+

Every endpoint requires a bearer token. The single token grants read and write access to all instances in that deployment. Use separate deployments when you need separate access boundaries.

How long are artifacts kept?+

The deployment configures an R2 lifecycle rule to expire objects seven days after their latest upload. Deletion is asynchronous, so this is a retention policy rather than an exact deletion deadline. Re-uploading a key refreshes its lifetime.

Does it work with Bazel or remote execution?+

Remoshu implements the small HTTP action-cache and content-addressable-storage surface used by moon v2. It doesn’t expose gRPC or a general remote execution service. See the HTTP contract for supported endpoints.
