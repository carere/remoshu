# Remoshu identity

Remoshu is a contraction of “Rimōtokyasshu”, meaning “remote cache”, as explained by the project
owner. The current mark expresses that meaning through an open storage enclosure, a cached tile
inside it, and a detached packet arriving from outside. It uses geometric negative space rather
than letterforms. The wordmark is lowercase Space Grotesk with a vermilion full stop.

- Paper: `#F6F3EC`
- Evergreen ink: `#253D34`
- Vermilion: `#D85C3F`
- Accessible vermilion text: `#B24630`
- Sage: `#E8ECDF`
- Body and display type: Space Grotesk Variable, served locally
- Code and labels: Geist Mono Variable, served locally

The current transparent PNG is at `apps/website/public/brand/remoshu-mark-v2.png`. It is used for the
website logo, favicon, and downloadable mark. The previous double-m direction is retained at
`apps/website/public/brand/remoshu-mark.png` for comparison. The editable website color definitions are in
`apps/website/src/tokens.css`. Font packages include their upstream licenses.

## Current direction (v2): remote cache pocket

Generated with the built-in image generation tool. The original transparent output is preserved
without raster post-processing.

> Use case: logo-brand
> Asset type: a finished transparent PNG logo symbol for Remoshu, an open-source remote build cache.
> Context: The name Remoshu is a contraction of "Rimōtokyasshu", meaning "remote cache". The owner rejected the previous mark because it looked like two stacked lowercase m letters. This is an entirely NEW design, not an edit of that mark.
> Primary request: Design a distinctive "remote cache pocket" emblem. A compact, bold, softly squared open enclosure holds a single solid square cache tile in its negative space. A purposeful opening on the upper right, with a small detached square packet just outside it, suggests a build artifact traveling from a remote machine into saved storage. Make the enclosure and inner tile feel like ONE beautifully balanced symbol with the detached packet as its sole accent. Use an inventive reductive silhouette and deliberate negative space, with the quiet precision of contemporary Japanese graphic identity design.
> Style: extremely simple flat vector-like brand mark, controlled rounded corners, geometric optical balance. Distinctive professional developer-tool identity; compact and legible at 24 pixels. Approximately three bold elements maximum. No literal letterforms.
> Color palette: ONE uniform solid vermilion ink #D85C3F. Fully opaque symbol, transparent surrounding background. Absolutely flat fill, no gradient, no material effects.
> Composition: one logo symbol centered on a square canvas; symbol occupies about 72% of canvas width, generous even margins. Large clean gaps that remain readable at favicon scale.
> Constraints: no letter m, no double m, no nested arches, no wordmark, no text, no Japanese characters or invented kanji, no cloud, no wifi symbol, no globe, no infinity sign, no generic circular refresh arrows, no decorative dots, no extra versions, no mockups, no shadow, no texture, no watermark. A single finished symbol only.
> Save the transparent PNG locally and return its file path if supported.
